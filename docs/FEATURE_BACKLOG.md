# Additional Features — Beyond Milestones

These ideas are **not committed MVP scope**. Re-rank after each milestone based on actual learning value.

## Musical creativity

- [ ] **Borrow-a-lick mode:** extract a short phrase, then create call-and-response variations.
- [ ] **Triad connection coach:** show where phrase notes land on nearby triad shapes.
- [ ] **Chord-change targeting:** practice landing on thirds, fifths, and sevenths as chords change.
- [ ] **Fretboard position explorer:** find alternate fingerings with position-shift tradeoffs.
- [ ] **Style comparison:** explain what makes two phrases feel different without copying entire works.
- [ ] **Phrase chaining:** connect saved licks into original improvised passages.
- [ ] **Constraint improvisation:** practice with only three notes, one string, or specific chord tones.

## Practice and feedback

- [ ] Adaptive spaced repetition based on weak techniques or forgotten phrases.
- [ ] Microphone-based timing/pitch feedback, with noise tolerance and calibration.
- [ ] Play-along metronome, loop regions, speed changes without pitch changes.
- [ ] Backing-track generation from chord progressions.
- [ ] Personalized weekly lessons using saved vocabulary and current goals.
- [ ] Guitar technique comfort preferences and alternate fingerings.

## Input and library

- [ ] Native camera scanning and automatic perspective correction.
- [ ] PDF import and multi-page extraction.
- [ ] MusicXML, Guitar Pro, MIDI, and other supported file imports/exports.
- [ ] Handwritten annotations and chord-diagram recognition.
- [ ] **Book notation legends as recognition context:** collect the notation legend pages from the owner's books (bends, slides, pre-bends, hold/release, dead notes, etc.) and give the relevant legend to the AI provider, or turn it into prompt rules, so each publisher's symbols are read correctly. Legends are copyrighted, so keep them private like scans.
- [ ] Search phrases by melodic contour, intervals, technique, or chord function.
- [ ] Offline/PWA support for saved exercises.

## Advanced ideas

- [ ] Interactive AI tutor that can answer questions about selected notes.
- [ ] Audio-to-tab from user-recorded original playing (separate difficult problem).
- [ ] Visual fretboard animation synchronized with playback.
- [ ] Optional community sharing of **user-created** exercises and original licks, subject to licensing safeguards.

## Backlog triage rule

Promote a feature only when it improves the central outcome: **taking an idea from existing music and applying it creatively elsewhere**.
