# Guitar Study Companion — workspace

Nx monorepo: Angular web app, Azure Functions API, and shared libraries.

```sh
nvm use && npm ci
npm run dev       # API :7071 + web :4200
npm run verify    # format, lint, test, typecheck, build, e2e
```

See [docs/DEVELOPMENT.md](../docs/DEVELOPMENT.md) for the layout, environment variables, and deployment, and [docs/TESTING.md](../docs/TESTING.md) for the e2e strategy.
